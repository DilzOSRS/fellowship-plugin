# Expedition types (2026-11-03)

The kinds of expedition, as the user broke them down on paper. Written up by Claude from the hints in the other docs, then confirmed by the user on 2026-11-03 ("Yeah that's pretty much it"), who added that dungeons need a party. A type is a shape a trip can have; one expedition can mix several (the Sailing Dungeon Voyage is a dungeon, multi-stage and dangerous).

| Type | What makes it that type | Examples (built or planned) |
|---|---|---|
| **Safe** | No threat: never fails, nobody gets injured | Fortify, Grand Exchange trade, Transmute |
| **Dangerous** | Has a threat level; can fail (no loot) and injure followers. Takes Combat followers (v1 plan) | Swamp Caves (3), Dorgeshuun (8), Sailing Dungeon Voyage (15–17), Barrows Raid (20) |
| **Dungeon** | Needs **several followers to form a party** (user, 2026-11-03) | Dorgeshuun (exactly 3), Sailing Dungeon Voyage, Barrows Raid (3) |
| **Skilling** | Safe, for the Skiller tree; each Skiller in the party makes it faster (~~idea: a flat % off per Skiller, capped~~ built 2026-11-03: 25% off per Skiller, only 3 count, and on every expedition, not just skilling ones) | Fortify, Prepping for the Sailing Dungeon |
| **Class-only** | Only one class can go, usually alone | Grand Exchange trade (Merchant), Transmute (Alchemist) |
| **"Do X while they're away"** | What the player does in OSRS while it runs decides the loot (read-only triggers) | Barrows Raid (1 bundle per chest), Slayer Master's hunt |
| **Multi-stage** | Split into stages that run one after another | Sailing Dungeon Voyage (3 × 30 min) |
| **Unlock** | Its job is to open something: a follower, another expedition, a boat | Swamp Caves' first run (Skillers), Fortify's first run (2nd Adventurer), Prepping for the Sailing Dungeon (the voyage) |
