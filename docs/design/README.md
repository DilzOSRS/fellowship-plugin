# Design docs (work in progress)

**These are rough, work-in-progress design notes**, brainstormed in claude.ai between coding sessions (2026-10-31 to 2026-11-02). Nothing here is built yet. Numbers are first guesses and will change through playtesting before v1 is submitted to the Plugin Hub.

The originals live in the "Fellowship Plugin" Project on claude.ai; these are copies so Claude Code can read them. If they disagree with `CLAUDE.md` or the code, the code and `CLAUDE.md` describe what is built; these describe what is planned.

| Doc | What's in it |
|---|---|
| `roadmap-items-bundles-stats.md` | **Start here.** The step-by-step plan for items, stats and bundles (Stages A, B, C), follower tags, class base stats, the item budget system, level requirements, threat checks |
| `item-list-v1.md` | The v1 item list, Common to Rare: names, icons, stats |
| `bundles-v1.md` | Every bundle: sources, drop chances, rarity odds, item pools, weights |
| `tutorial-phase.md` | The opening path as the tutorial, and Swamp Caves at threat 3 |
| `expedition-chart.md` | Every expedition, built and planned, plus Sailing Dungeon threat numbers |
| `brainstorm-2026-10-31-items-bundles-followers.md` | The first brainstorm: inspirations, the tag system, Sailor tree, Slayer Master, parked follower ideas |

Build order: Stage C in the roadmap. Code work starts there, one step at a time, each tested in-game.
