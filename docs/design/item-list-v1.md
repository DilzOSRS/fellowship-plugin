# v1 item list: Common to Rare (B2, draft 2026-11-01)

Roadmap step B2. Built from the item types in B1 (`roadmap-items-bundles-stats.md`) and the budget rules there: Common 2, Uncommon 4, Rare 7 for a single-tag item; Generic −1, combo +1. Level to equip: Common 1, Uncommon 10, Rare 15. **Soft rules:** the user can go over or under budget on purpose. Items can mix stats (user, 2026-11-01). Icons are OSRS items drawn by RuneLite (check the exact `ItemID` names when building). Epic and Legendary come later; dark items are on hold.

Columns: **Budget** = what the rules give; **Total** = the stats added up (MAG counts as 1 point).

## Notes
- **Leather gives ATK as well as DEF** and **Robes give MAG**, so the armour types have personality: Plate is pure defence, Leather is offence plus defence, Robes are magic.
- **Staves give MAG**, which (with Robes) makes the Wizard's gear clearly magic.
- Mixed stats show up on the card as separate lines; the worked-out ATK and DEF (including MAG) is shown too (roadmap Stage C step 2).
- **Check these icon names exist when building:** silver necklace, the Barrelchest anchor's Bounty Hunter variant, Mermaid's trident, brown robe top, white robe top. If one doesn't exist, pick the closest OSRS item.
